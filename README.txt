TWISTED SKIES PUBLISHING WEBSITE

This is a simple static website that can be hosted for free on GitHub Pages.

FILES
- index.html: the page itself
- styles.css: design and responsive layout

TO PREVIEW
Open index.html in a web browser.

BEFORE PUBLISHING
1. Replace the placeholder Amazon and Goodreads links in index.html.
2. Replace your-email@example.com with the email address you want displayed.
3. If you want real book covers, add image files to this folder and replace the styled placeholder cover blocks with <img> tags.
4. We can add or change any wording, sections, colors, or layout before publishing.

GITHUB PAGES
Once you're happy with the site, upload these files to a GitHub repository and enable GitHub Pages. Then point twistedskiespublishing.com to GitHub Pages using GoDaddy DNS.
